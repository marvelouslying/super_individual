说明
（1）npm严格执行package.json中的参数，并且package.json文件默认地址为D:\bytedance_project\conduit-realworld-example-app\backend。

（2）文件的物理地址和npm被强制锁定的工作区域并不相同，但是为了方便实验，不修改任何代码，在执行npm指令的时候需要牢记将文件放在指定的工作区域，也就是"D:\bytedance_project\conduit-realworld-example-app\backend"目录下。



修正：将新创建的.env文件放在npm指定的工作区域当中，也就是`backend` 目录

最终解释：

所以，您在配置数据库时遇到的问题，根本原因就是 `dotenv` 依赖了 `process.cwd()` 来寻找 `.env` 文件，而 `process.cwd()` 被 npm workspace 切换到了 `backend` 目录。解决方案您已经找到：把 `.env` 放在 `backend` 下，或者修改 `config.js` 强制指定路径。
